feat(P9): Docker / CI / 一键安装 / 文档索引

Docker
- 多阶段构建：node 构建前端 -> golang 构建后端 -> alpine 运行
- 前端产物在构建期覆盖占位页，确保 embed 进二进制的是真实前端
- 依赖清单单独一层，源码改动不会导致重新下载依赖
- 运行镜像 29 MB，非 root（uid 100），只挂载 /data
- HEALTHCHECK 打 /api/health
- docker-entrypoint.sh：校验数据目录可写后再启动
  （否则 SQLite 会在用户走完初始化向导后才失败，报错时机很糟）
- 容器内**不做任何隐式初始化**，首启初始化仍由面板向导完成

CI（.github/workflows/ci.yml）
- 四个 job：后端（gofmt/vet/build/test -race）、前端（tsc+build）、
  端到端（make e2e）、Docker（构建 + 起容器查健康检查）
- 端到端跑在 CI 上，保证"每个新功能必须配端到端断言"这条纪律能被机器执行

Release（.github/workflows/release.yml）
- 主控 linux/amd64 + arm64；Agent 覆盖 linux/darwin/windows × amd64/arm64
- 产出 checksums.txt，Release notes 自动生成

一键安装（deploy/install-master.sh）
- 依赖自举：缺 curl 自动装（apt/apk/dnf/yum/pacman/zypper）
- 自动解析最新版本；MMX_VERSION 可固定版本
- sha256 校验（取官方 checksums.txt）+ ELF 魔数兜底校验
- **冒烟测试通过后才注册 systemd**：避免装出一个 exit 127 的坏 unit
- systemd unit 带加固项（NoNewPrivileges / ProtectSystem / ProtectHome / ReadWritePaths）
- 交互提示走 stderr + read -t 兜底（管道执行时不会卡死）
- 冒烟测试 cd 到临时目录，不污染当前工作目录

配套
- deploy/nginx.conf.example：WebSocket（Agent 网关 + 探针推送）显式透传 Upgrade，
  订阅出口关闭缓冲与缓存，并说明 MMX_TRUST_PROXY 的必要性
- docs/README.md：文档索引 + **关键设计决定表**（把散落在代码注释里的
  "为什么这样做"汇总成一张表）
- .golangci.yml：只开真正能抓到问题的检查项
- THIRD_PARTY_NOTICES.md：逐项列出依赖与许可，并说明 MMX 不分发 Xray 二进制
